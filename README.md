# Interview Copilot

macOS overlay для **тренировки** на технических созвонах: слушает звук из Zoom / Google Meet / Teams, распознаёт речь и показывает короткие тезисы для ответа.

> Используйте для подготовки и разборов записей. На реальных экзаменах/собеседованиях без согласия сторон подсказки неэтичны.

## Как это работает

1. Прозрачное окно поверх всех приложений.
2. Скрытое окно захватывает **системный звук** через `getDisplayMedia` + loopback (нужно разрешение «Запись экрана» в macOS).
3. Аудио режется на чанки (по умолчанию 6 с). Тихие чанки отбрасываются по RMS, не доходя до API.
4. Chunk → Whisper → накопленный хвост из последних 4 чанков → если похоже на вопрос → GPT даёт 3–5 буллетов.
5. Ответы копятся в историю; можно скопировать тезисы в буфер или вставить вопрос вручную.

## Требования

- macOS 13+
- Node.js 20+
- API-ключ OpenAI (Whisper + chat)

## Установка

```bash
cd ~/interview-copilot
npm install
npm run dev
```

Ключ OpenAI вводится в UI: **Профиль → Ключ OpenAI**. Он шифруется через `safeStorage` и лежит в `~/Library/Application Support/Interview Copilot`. Как запасной вариант читается `OPENAI_API_KEY` из `.env` (`cp .env.example .env`).

При первом запуске macOS запросит:

- **Запись экрана** — для звука созвона
- **Микрофон** — опционально, если будете говорить сами

В dev-режиме в *Системные настройки → Конфиденциальность → Запись экрана* нужно включить **Electron** (кнопка «Запросить доступ» в UI покажет точный путь для добавления через «+»). После выдачи прав приложение надо перезапустить.

## Хоткеи

| Комбинация | Действие |
|------------|----------|
| `⌘⇧Space` | скрыть / показать overlay |
| `⌘⇧L` | старт / стоп прослушивания |
| `⌘⇧K` | компактный режим (только вопрос и тезисы) |
| `⌘Enter` | отправить ручной вопрос |

Если комбинация занята другим приложением, UI об этом скажет.

## Настройки

**Профиль** в UI: ключ OpenAI, роль, стек, заметки об опыте (уходят в промпт), язык ответов, длина чанка, порог тишины.

Переменные в `.env`:

| Переменная | По умолчанию |
|------------|----------------|
| `OPENAI_API_KEY` | — (или ключ из UI) |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` |
| `STT_MODEL` | `whisper-1` |
| `COACH_MODEL` | `gpt-4o-mini` |
| `CHUNK_SECONDS` | `6` |
| `COPILOT_DEBUG` | — (`1` открывает devtools скрытого capture-окна и логирует чанки) |

## Сборка

```bash
npm run typecheck   # tsc по обоим проектам
npm run build       # typecheck + electron-vite build в out/
npm run start       # запустить собранное
npm run dist        # .dmg для arm64 и x64 в release/
npm run dist:dir    # распакованное .app без dmg (быстрее)
```

Сборка подписывается ad-hoc (`identity: null` в `electron-builder.yml`), без нотаризации. Первый запуск: правый клик → «Открыть». Для распространения нужен сертификат Apple Developer — тогда уберите `identity` и включите `notarize`.

Иконка не задана, используется дефолтная Electron. Чтобы поставить свою — положите `build/icon.icns`.

## Ограничения

- Задержка ≈ длина чанка + время Whisper/GPT (обычно 7–10 с).
- Нет локального STT — только OpenAI API.
- Захват звука зависит от `desktopCapturer`; на некоторых версиях macOS нужен перезапуск после выдачи прав.
- Whisper иногда галлюцинирует на шуме; типовой мусор («спасибо за просмотр» и т.п.) отфильтрован, но не весь.
